Analizador de Archivos

Analizá varios archivos en VirusTotal de una sola vez y mirá el informe de cada uno.

Abriste el archivo directamente. Ejecutá python proxy.py y entrá a http://localhost:8000; si no, el navegador bloquea las llamadas a VirusTotal.

API pública gratuita: 4 peticiones por minuto y 500 por día. La app espera 15 s entre peticiones para no pasarse.

Arrastrá tus archivos acá o hacé clic para elegirlos

Máximo 32 MB por archivo. No subas archivos privados: lo que se sube a VirusTotal queda disponible para la comunidad de seguridad. Si VirusTotal ya conoce el archivo, se usa ese informe sin subirlo.
